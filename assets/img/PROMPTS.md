# Prompts pour les images du site Kebab 37

Chaque image doit être générée en **PNG détouré (transparent)** ou sur **fond noir pur** pour s'intégrer parfaitement avec les halos rouge/orange du site.

## Style de base (à coller à chaque prompt)

```
PNG cut-out, transparent background OR pure black background,
dramatic studio lighting, warm red and orange rim light glow,
ultra realistic food photography, high contrast, sharp focus,
premium fast-food style, appetizing, steam, fresh ingredients,
shot with 50mm lens, shallow depth of field, 8K, hyper detailed
```

Format conseillé : **carré 1:1, 2048×2048**, export en **PNG transparent**.
Sortie attendue : produit centré, vide tout autour pour laisser la lueur CSS faire son travail.

## Conseils pour Midjourney / DALL-E / Flux

- **Midjourney** : ajoute à la fin `--ar 1:1 --style raw --v 6` et précise `transparent background, no shadow on background`.
- **DALL-E 3** : demande explicitement *"isolated subject on pure black background, ready for web compositing"*.
- **Flux / SDXL** : utilise un LoRA "product photography" si dispo, et active le passage par un outil de détourage (`rembg`, `remove.bg`) pour obtenir un PNG vraiment transparent.

## Workflow recommandé

1. Génère chaque image en 2048×2048.
2. Détoure-la (transparent PNG) avec [remove.bg](https://www.remove.bg) ou `rembg` en CLI.
3. Sauvegarde avec **exactement le nom de fichier indiqué** dans `assets/img/`.
4. Recharge le site — la lueur CSS fait le reste automatiquement.

> Si une image manque, le fond conserve son halo rouge/orange grâce à la fallback CSS — donc tu peux ajouter les visuels au fur et à mesure.
